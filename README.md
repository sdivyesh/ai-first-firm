# AI-first firm

How a 29-person software and data firm in Pune runs on AI, one piece at a time, in public.

I'm Divyesh Shah, CTO and co-founder of Giant Leap Systems. For the past year we have been doing two things at once: helping build models that run inside industrial plants, and running more of our own firm on AI than I'd have believed possible. This repository holds the second: the small systems we built for ourselves, as they are, with what each one cost and what was rolled back.

The stance under all of it: the AI does every step that can be undone. One person does the one that can't.

## The pieces

| Piece | What it is | Status |
| --- | --- | --- |
| [desk-and-canon](desk-and-canon/) | A memory for the firm, and a record of what it claims. Two places, four verbs, one human action. | In daily use; two verbs experimental |

Each piece is a folder with its own README and the files to install it. New pieces arrive with the post that describes them, not before.

## How it grows

- `posts/` holds every post as published, dated, with a header saying what it added here.
- `CHANGELOG.md` has one line per addition, newest first.
- A piece's status changes in its own README and in the table above when something graduates from experimental or is rolled back.

## Rules

- Nothing from the firm's own Canon. No client work. Nothing about how we do outbound; that is a separate system and it is not public.
- Every number is one we measured. Every rollback is recorded.
- Plain words. If a sentence needs a buzzword to stand up, it comes out.
